Agent Reminders privacy

Updated 12 October 2026. Agent Reminders is an independent open-source project. It is not affiliated with Apple or Google.

Your browser, your reminders

The public playground stores lists and reminders in this browser's local storage. It starts with fictional examples. There is no shared reminder database, password gate, advertising, analytics, or hosted agent execution. Another person using this browser profile can access its saved reminders.

Google accounts

Connecting is optional. Google handles account selection, sign-in, and consent in its own window. This app never asks for your Google password. Calendar access is read-only. Google Tasks is read-only unless you separately enable completion writeback; the app then requests Tasks write permission.

You choose calendars or task lists, preview their contents, and explicitly import them into this browser. Requests go directly to Google. Access tokens remain in memory, expire, and are not saved in local storage, sent to this project's server, or included in source code. Imported titles, notes, dates and source identifiers are saved locally so you can refresh without duplicates. Selected Calendar events are imported within the displayed date window.

Google data is used only for these visible import, refresh and opted-in completion features. It is not sold, used for advertising, or transferred for training general AI models. Agent Reminders' use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Disconnect clears the in-memory connection; imported copies remain until you delete them locally. Revoke access to remove the app's Google grant. You can also remove the grant through your Google Account's third-party connections settings. Clearing this site's browser data removes local copies and settings. Google sign-in and API requests are also governed by Google's privacy policy.

Apple Reminders

A browser cannot access EventKit. The optional iOS companion asks the operating system for Reminders permission. Choose lists, preview them, and confirm a local import. The local import does not upload reminders or change Apple Reminders. Simulator imports are always fictional. This app never collects Apple ID passwords.

Hosting and your own server

Cloudflare serves the public website and receives ordinary web-request information such as IP addresses. This project does not add a visitor tracking service. A self-hosted server is a separate mode with its own private storage, authentication, attachments, and optional agent/device APIs. The browser-local Accounts flow does not send imported provider data to that server.

Questions and source

See the source repository and its Security policy. Raise privacy questions through GitHub without including passwords, tokens, personal reminder contents, or account screenshots.
