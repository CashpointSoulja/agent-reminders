Agent Reminders privacy

Updated 12 October 2026. Agent Reminders is an independent open-source project. It is not affiliated with Apple or Google.

Your browser, your reminders

The public app starts with fictional examples and keeps lists and reminders in this browser's local storage. Imports stay on this device unless you explicitly enable Cloud Storage. There is no publicly shared reminder workspace, password gate, advertising, analytics, or hosted agent execution. Another person using this browser profile can access its saved reminders.

Optional private Cloudflare storage

Enable Cloud Storage encrypts this device's reminders, sections and safe import metadata before uploading them to an isolated Cloudflare SQLite Durable Object. Cloudflare stores the current encrypted document and two previous encrypted revisions. It does not receive the recovery master key or encryption key. A separately derived private capability authorizes requests; only its hash is stored. Google OAuth tokens, Apple credentials and the recovery code are excluded from backup documents.

Anyone with your recovery code can read or change that private cloud document. Keep it privately; it cannot be recovered if lost. Remember on This Device is optional and stores the code in this browser or companion's local storage. Otherwise the connection lasts for the open page. Entering a code on another device first opens a preview; you choose which version to use. A conflicting or failed save keeps local reminders in place. An interrupted setup may already have created the encrypted document: keep the displayed code and retry the same setup.

Disconnect removes this browser's cloud connection without deleting its local reminders or the encrypted cloud document. Clearing this site's browser data removes local copies, settings and any remembered code; it does not delete cloud storage. Encryption does not protect an unlocked browser profile, a compromised device or malicious code served by a compromised frontend. Cloudflare still receives normal network and storage metadata.

Google accounts

Connecting is optional. Google handles account selection, sign-in, and consent in its own window. This app never asks for your Google password. Calendar access is read-only. Google Tasks is read-only unless you separately enable completion writeback; the app then requests Tasks write permission.

You choose calendars or task lists, preview their contents, and explicitly import them into this browser. Provider requests go directly to Google. Access tokens remain in memory, expire, and are not saved in local storage, sent to this project's server, included in cloud backups or included in source code. Imported titles, notes, dates and source identifiers are saved locally so you can refresh without duplicates; they are also encrypted and saved to Cloudflare if you explicitly enable Cloud Storage. Selected Calendar events are imported within the displayed date window.

Google data is used only for these visible import, refresh and opted-in completion features. It is not sold, used for advertising, or transferred for training general AI models. Agent Reminders' use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Disconnect clears the in-memory connection; imported copies remain until you delete them locally. Revoke access to remove the app's Google grant. You can also remove the grant through your Google Account's third-party connections settings. Clearing this site's browser data removes local copies and settings. Google sign-in and API requests are also governed by Google's privacy policy.

Apple Reminders

A browser cannot access EventKit. The optional iOS companion asks the operating system for Reminders permission. Choose lists, preview them, and confirm an import. Previewing does not upload reminder contents. Confirmed copies stay on this device unless you explicitly enable Cloud Storage, which encrypts and saves them to Cloudflare. Importing, cloud backup and restoring these copies do not change Apple Reminders or Google Calendar. Google Tasks completion requires its separate permission and explicit opt-in. Simulator imports are always fictional. This app never collects Apple ID passwords.

Hosting and your own server

Cloudflare serves the public website and optional encrypted private storage, and receives ordinary web-request information such as IP addresses. This project does not add a visitor tracking service. A self-hosted server is a separate mode with its own private storage, authentication, attachments, and optional agent/device APIs. Optional Cloud Storage does not grant access to those APIs or change the source Apple or Google account.

Questions and source

See the source repository and its Security policy. Raise privacy questions through GitHub without including passwords, tokens, personal reminder contents, or account screenshots.
